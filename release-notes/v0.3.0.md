# Ad Network 0.3.0

Stats for your ads, and tasks on your to-do list when ads need attention. This is the first release since 0.1.0, so it includes the 0.2.0 changes.

## New in 0.3.0

- **Works with [To-do Hub](https://github.com/bignall/todo-hub).** When To-do Hub is active, Ad Network adds:
  - **Fix ad "title"** for each published ad that won't show (no image, no link, its size turned off, third-party code not allowed) or whose cloaked link was deleted or no longer pays. High priority when the offer no longer pays.
  - **Add ads for N empty ad slots** when a placement that's on has no ad of the size it uses, on computers or phones.

  Tasks are marked done when fixed and removed when an ad is paused or deleted. Checked when ads or settings are saved and once a day. Works with To-do Hub on this site or connected to a hub elsewhere. Turn it off under **Ads → Settings → To-do list**.

## From 0.2.0

- **Stats page** (Ads → Stats): served, viewed, clicks and CTR for any date range, per ad, per placement and per page, with daily charts and CSV export.
- Daily totals are rolled up every hour, so detailed events can be pruned after a set number of days (90 by default) without losing history.
- Shows clicks recorded by Affiliate Link Cloaker for each ad (needs Link Cloaker 0.4.0).

## Install

Download `ad-network-0.3.0.zip` below, then in WordPress go to **Plugins → Add New → Upload Plugin** and choose **Replace current with uploaded**. Your ads, stats and settings are kept.

Requires PHP 8.1+ and WordPress 6.4+. Affiliate Link Cloaker and To-do Hub are optional.
